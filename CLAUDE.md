# Nouran Tarek Soliman — Academic Portfolio

Static academic portfolio site. Vanilla HTML/CSS/JS — no build step, no framework, no package.json. Hosted on GitHub Pages with a custom domain via `CNAME`.

## File structure

```
index.html            # Entire site — all CSS and JS are inline
assets/images/
  profile_pic.webp    # Primary hero image (360×360, ~12KB)
  profile_pic-cmpr.png # PNG fallback for browsers without WebP support
js/
  widget-summary.js   # PlumX academic metrics widget — do not edit
  plumx-xss.js        # PlumX XSS script — do not edit
CNAME                 # Custom domain config
```

## Design system

CSS custom properties defined in `:root`:

| Token | Value | Role |
|---|---|---|
| `--primary` | `#1a2332` | Deep navy — headings, footer bg |
| `--secondary` | `#8b4513` | Saddlebrown — accents, borders, links |
| `--accent` | `#c19a6b` | Warm gold — decorative underlines |
| `--text` | `#2c3e50` | Body text |
| `--text-light` | `#5a6a7a` | Secondary/muted text |
| `--bg` | `#fdfbf7` | Page background (warm parchment) |
| `--bg-alt` | `#f5f1e8` | Section alternate background |

**Font roles:**
- `Cormorant Garamond` — `h1`, `h2`, `h3` section headings
- `Crimson Pro` — labels, nav, subtitles, `.pub-badge`
- `Source Sans 3` — body copy

## Conventions

**CSS/JS are inline.** All styles live in `<style>` inside `<head>`. All scripts live in `<script>` before `</body>`. Do not extract to separate files unless there is a compelling reason.

**Images.** Use `<picture>` with a `<source type="image/webp">` and an `<img>` PNG fallback. Always include `width` and `height` attributes on `<img>` to prevent layout shift. Profile image must be 360×360px WebP ≤50KB.

**External links.** Always `target="_blank" rel="noopener noreferrer"`.

**Animations.** Use compositor-friendly properties only (`transform`, `opacity`). The `prefers-reduced-motion` media query at the bottom of `<style>` disables all motion — keep it updated when adding new animations.

**Body text.** Left-aligned only. Do not use `text-align: justify`.

## Adding content

**New publication:** Copy an existing `<article class="publication-card">` block. Abstract inline should be ≤3 sentences — link out to the full abstract. Add DOI and publisher. Put newest entries first.

**New nav section:** Add `<li><a href="#section-id">Label</a></li>` to `<nav ul>` and add the matching `id` on the section element.

**Profile image update:** Replace `assets/images/profile_pic.webp` with a new 360×360px WebP file ≤50KB. Keep the PNG fallback in place.

## Third-party widget

PlumX metrics (`js/widget-summary.js`) is a vendored, minified third-party bundle. It loads jQuery 1.10.2 from a Google CDN at runtime. Do not edit this file. It is currently applied only to the Master's thesis entry.

## Do not

- Add npm, a bundler, or a framework — zero-dependency is intentional
- Use `text-align: justify` anywhere
- Use `target="_blank"` without `rel="noopener noreferrer"`
- Ship images larger than their rendered display size
- Animate layout-bound properties (`width`, `height`, `top`, `margin`)
